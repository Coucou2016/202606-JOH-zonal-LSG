# Review Round 4 — Data Accuracy & Completeness

You are reviewing a manuscript for Journal of Hydrology.
The manuscript is at: `paper/manuscript.md` in the GitHub repository.

**Your task for Round 4:** Verify data accuracy and completeness. Focus on:
1. **Numerical consistency** — Do the same numbers appear consistently across Abstract, Results, Discussion, and Conclusion? For example, the Carlisle RMSE of 0.1464 and 0.0964 at B=4 should be the same everywhere.
2. **Table completeness** — Are all compared models listed? Are sample sizes, event counts, and cell counts correctly stated?
3. **Statistical reporting** — Are confidence intervals, p-values (if any), and bootstrap details properly reported? Is the bootstrap method (percentile, 10,000 replicates, seed 42) described consistently?
4. **Missing numbers** — Are there any claims in the text that lack supporting numbers? Are there numbers that should be reported but are not?
5. **Protocol clarity** — Is it clear which protocol (B=4, B=6, LOOCV, fixed split, official) is being used for each reported number?

Provide a structured review with:
- **Major issues** (must fix)
- **Minor issues** (should fix)
- **Suggestions** (optional improvements)

Do NOT edit the manuscript directly. List your findings concisely.
